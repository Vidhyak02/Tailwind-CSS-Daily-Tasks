# 🏨 Day 5 - Tailwind CSS Task 5

## 🌟 Luxury Hotel Website

This project is a modern and responsive **Luxury Hotel Website** created using **HTML5** and **Tailwind CSS**.

The website provides an elegant and premium user interface for a luxury hotel, featuring hotel rooms, services, booking options, and other essential sections.

---

## 🛠️ Technologies Used

* HTML5
* Tailwind CSS
* Google Fonts
* Unsplash Images
* Responsive Design

---

## ✨ Features

* 🏨 Luxury Hotel Landing Page
* 🌟 Attractive Hero Section
* 🧭 Responsive Navigation Bar
* 📅 Hotel Booking Section
* 🛏️ Luxury Rooms Section
* ℹ️ About Hotel Section
* 💆 Hotel Services Section
* 🏊 Infinity Pool Service
* 🍽️ Fine Dining Section
* 🚗 Private Transport Service
* ✨ Hover Effects and Transitions
* 📱 Fully Responsive Design
* 🖼️ High-Quality Unsplash Images
* 🦶 Professional Footer

```bash

```

2. Navigate to the project folder:

```text
Tailwind-CSS-Daily-Tasks/
│
└── Daily_Tasks/
    │
    └── Day_5_Tailwind-CSS_Task5/

        └── Day18.html
```
