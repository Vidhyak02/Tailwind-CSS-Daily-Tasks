# 👗 STYLEHUB - Clothing Store Website

## 📌 Project Description

STYLEHUB is a modern and responsive Clothing Store Website created using **HTML5** and **Tailwind CSS**.

The website provides a stylish online shopping experience with different clothing categories, featured products, new collections, best sellers, special offers, and more.

---

## 🚀 Technologies Used

* HTML5
* Tailwind CSS
* Font Awesome
* Responsive Web Design

---

## ✨ Website Features

* Responsive Navigation Bar
* Attractive Hero Section
* Clothing Categories
* Featured Products
* New Collection Section
* Best Sellers Section
* Special Discount Offer
* Newsletter Subscription
* Responsive Footer
* Mobile-Friendly Design

## 🛍️ Website Sections

### 1. Navigation Bar

The navigation bar includes:

* Logo
* Home
* Shop
* Collection
* Products
* Contact
* Search Icon
* Wishlist Icon
* Shopping Bag Icon

### 2. Hero Section

An attractive fashion banner with:

* Main Heading
* Fashion Description
* Shop Now Button

### 3. Categories Section

Different shopping categories:

* Women
* Men
* Kids
* Accessories

### 4. Featured Products

Displays trending fashion products with:

* Product Image
* Product Name
* Price
* Add to Cart Button

### 5. New Collection

Displays the latest fashion collection with an attractive image and call-to-action button.

### 6. Best Sellers

Shows popular and most-loved products with ratings and prices.

### 7. Special Offer & Newsletter

Includes:

* Flat 50% Discount Offer
* Shop Sale Button
* Email Subscription Section

### 8. Footer

The footer contains:

* Store Information
* Quick Links
* Customer Service
* Contact Details
* Social Media Icons

## 📱 Responsive Design

The website is designed to work smoothly on:

* 💻 Desktop
* 💻 Laptop
* 📱 Mobile
* 📱 Tablet

Tailwind CSS responsive utility classes are used to provide a better user experience across different screen sizes.
