# 🍳 Recipe Finder Website

## 📌 Project Description

This project is a **Recipe Finder Website** created using **HTML and Tailwind CSS**.

The website helps users explore different recipes, food categories, ingredients, cooking tips, and popular dishes through a simple and attractive user interface.

---

## ✨ Features

* Responsive Navigation Bar
* Attractive Hero Section
* Recipe Search Bar
* Search by Ingredients Section
* Popular Recipes Section
* Recipe Categories
* Why Choose Us Section
* Recipe of the Day
* Cooking Tips Section
* Newsletter Subscription
* Footer Section
* Responsive Design

---

## 🛠️ Technologies Used

* HTML5
* Tailwind CSS
