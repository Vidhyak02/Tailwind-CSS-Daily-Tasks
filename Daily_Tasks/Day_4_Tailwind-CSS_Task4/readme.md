# 🌿 Day 4 - Tailwind CSS Task 4

This repository contains my **Day 4 Tailwind CSS Daily Task**.

## 📌 Project Overview

A responsive and attractive website created using **HTML** and **Tailwind CSS**. This project focuses on building a modern user interface using Tailwind CSS utility classes.

## 🛠️ Technologies Used

* HTML5
* Tailwind CSS
* Google Fonts
* Responsive Design
* Unsplash Images

## ✨ Features

* Responsive Navigation Bar
* Attractive Hero Section
* Modern UI Design
* Tailwind CSS Utility Classes
* Responsive Grid Layout
* Image Cards
* Hover Effects
* Clean and User-Friendly Interface
* Responsive Design for Different Screen Sizes

1. Clone this repository:

```bash

```

```text
Daily_Tasks/Day_4_Tailwind-CSS_Task4
```
