# 🌴 Kerala Tourism Website

A responsive and attractive **Kerala Tourism Website** created using **HTML5 and Tailwind CSS**. This project showcases popular tourist destinations, Kerala culture, travel experiences, packages, and beautiful travel galleries.

---

## 📌 Project Details

* **Repository:** Tailwind-CSS-Daily-Tasks
* **Task:** Day 8 Tailwind CSS Task
* **Technologies Used:** HTML5, Tailwind CSS
* **Project Type:** Tourism Website

---

## ✨ Features

* Responsive Navigation Bar
* Attractive Hero Section
* Popular Kerala Tourist Destinations
* About Kerala Section
* Travel Experiences
* Kerala Food and Culture
* Best Time to Visit
* Travel Packages
* Kerala Travel Gallery
* Responsive Footer
* Hover Effects and Transitions
* Fully Responsive Design

## 🌟 Website Sections

### 1️⃣ Navigation Bar

A responsive navigation bar with links to different sections of the website.

### 2️⃣ Hero Section

An attractive welcome section introducing Kerala as **"God's Own Country"**.

### 3️⃣ Popular Destinations

Showcases famous tourist places in Kerala:

* 🌿 Munnar
* 🚤 Alleppey
* 🌲 Wayanad
* 🏙️ Kochi
* 🏖️ Kovalam
* 🐘 Thekkady

### 4️⃣ About Kerala

Provides information about Kerala, its natural beauty, and tourist attractions.

### 5️⃣ Things To Do

Highlights popular travel experiences such as:

* 🚤 Houseboat Ride
* 🥾 Trekking
* 🐘 Wildlife Safari
* 🏖️ Beach Visit

### 6️⃣ Food & Culture

Displays Kerala's traditional food, festivals, and cultural experiences.

### 7️⃣ Best Time to Visit

Provides information about the different seasons to visit Kerala.

### 8️⃣ Travel Packages

Displays different travel packages for visitors.

### 9️⃣ Kerala Travel Gallery

A gallery section showcasing beautiful travel images.

### 🔟 Footer

Contains quick links, contact information, and newsletter subscription.

## 🚀 How to Run

1. Download or clone the repository.

```bash
git clone https://github.com/Vidhyak02/Tailwind-CSS-Daily-Tasks.git
```

2. Navigate to the project folder.

```bash
cd Tailwind-CSS-Daily-Tasks/Daily_Tasks/Day_8_Tailwind-CSS_Task8
```

3. Open the `Day21.html` file in your browser.
