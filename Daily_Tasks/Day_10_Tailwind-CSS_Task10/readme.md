# 🏨 Hotel Booking Website

A modern and fully responsive **Hotel Booking Website** built using **HTML5** and **Tailwind CSS**.

## 🌐 Live Preview

Add your GitHub Pages / Live Demo link here.

## 📌 Project Overview

This project is a responsive hotel booking website designed with a modern and attractive user interface. It provides users with hotel information, room details, amenities, gallery images, guest reviews, and booking options.

The website is designed to work smoothly across different devices such as **mobile, tablet, laptop, and desktop**.

## ✨ Features

* 📱 Fully Responsive Design
* 🧭 Responsive Navigation Bar
* 🏨 Attractive Hero Section
* 📅 Hotel Booking Form
* ℹ️ About Hotel Section
* 🛏️ Room Details and Pricing
* ⭐ Hotel Amenities Section
* 🖼️ Hotel Gallery
* 💎 Why Choose Us Section
* 💬 Guest Testimonials
* 📧 Newsletter Subscription
* 📞 Contact Information
* 🦶 Responsive Footer

## 🛠️ Technologies Used

* HTML5
* Tailwind CSS
* Font Awesome Icons
* Google Fonts
* Unsplash Images

## 📱 Responsive Design

The website is designed to provide a seamless experience across multiple screen sizes:

* 📱 Mobile Devices
* 📱 Tablets
* 💻 Laptops
* 🖥️ Desktop Screens

Tailwind CSS responsive utility classes such as `sm:`, `md:`, and `lg:` are used to make the website responsive.

1. Clone the repository:

```bash

```

2. Navigate to the project folder:

```bash
cd Tailwind-CSS-Daily-Tasks/Daily_Tasks/Day_10_Tailwind-CSS_Task10
```
